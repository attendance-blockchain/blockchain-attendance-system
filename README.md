# Blockchain-Based Student Attendance System

## Problem Statement
Traditional attendance systems are prone to manipulation and lack transparency.

## Proposed Solution
This project uses blockchain technology to record student attendance in an immutable and transparent way.

## Objectives
- Secure attendance records
- Prevent data manipulation
- Improve transparency

## Technologies Used
- Solidity
- Ethereum Blockchain
- Remix IDE
- HTML, JavaScript
- GitHub

## How the System Works
1. Lecturer marks student attendance
2. Attendance data is stored on the blockchain
3. Records cannot be altered or deleted

## Conclusion
The system ensures secure and tamper-proof attendance management using blockchain technology.
